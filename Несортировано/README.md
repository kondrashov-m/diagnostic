## ✨ Что нового в v0.2

### 🎯 Основные улучшения
- ✅ **Потоковая загрузка** - обход ошибки 413, можно грузить 100+ файлов
- ✅ **Спектрограммы для ВСЕХ файлов** - больше не пропадают  
- ✅ **3 кнопки скачивания архивов** со спектрограммами:
  - 📊 Исходные спектрограммы
  - 🔧 Обработанные спектрограммы
  - 🎵 Спектрограммы шумов

## 🎯 Обработка звука
- **Продвинутое шумоподавление** с настраиваемым уровнем (0-100%)
- **Автоматическая конвертация** в WAV формат для стабильности
- **Три версии каждого файла**: оригинал, очищенный, выделенный шум
- **Поддержка форматов**: WAV, MP3, FLAC, M4A, AAC

## 📊 Визуализация и анализ
- **Высококачественные спектрограммы** для всех файлов
- **Сравнение результатов** в реальном времени
- **Аудио-плееры** для прослушивания всех версий
- **Детальная статистика** обработки
